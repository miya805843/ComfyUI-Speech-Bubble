# Custom Fonts Directory

You can place your custom TrueType/OpenType font files (`.ttf`, `.otf`, `.ttc`) here.
Any font placed in this directory will be automatically detected and displayed at the top of the font selection list in the ComfyUI node!

### 日本語フォントの追加について
お好みの漫画用フリーフォント（例: 源暎アンチック、アンチックセシル等）の `.ttf` または `.otf` ファイルをこのフォルダに配置すると、ComfyUIノードのフォント選択リストから簡単に選べるようになります。
